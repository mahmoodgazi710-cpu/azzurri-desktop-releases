# AZZURRI Admin for Windows

Download the latest Windows 10/11 x64 installer from [Releases](https://github.com/mahmoodgazi710-cpu/azzurri-desktop-releases/releases/latest).

This repository contains public installers and automatic-update files. Application development is maintained separately.

## Install and update

- Install version 1.0.3 or newer manually once to enable automatic updates.
- Future stable updates download in the background. Choose the in-app restart-and-update button when convenient.
- Local restaurant data is stored outside the installation folder. Updates create a backup before installation.
- The current installer is unsigned; Windows may show a publisher warning.

The release installer, `.exe.blockmap`, and `latest.yml` are distributed together. Do not replace individual release files manually.
